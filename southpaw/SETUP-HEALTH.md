# Southpaw — ซิงก์ข้อมูลสุขภาพจาก iPhone ทุกคืน

```
แอปสุขภาพ (iPhone) ──Shortcut ทุกคืน──▶ /api/southpaw-health ──▶ MongoDB ──▶ /southpaw/
```
ใช้ MongoDB กับ `SOUTHPAW_KEY` ตัวเดิม ไม่ต้องตั้งค่าเพิ่มใน Vercel

- Shortcut ส่งข้อมูลด้วย header `x-southpaw-key` (= ค่า `SOUTHPAW_KEY` ใน Vercel ไม่ใช่ PIN 2 หลัก)
- Workout ที่เข้ามาครั้งแรกของสัปดาห์นี้หรือสัปดาห์ก่อน เซิร์ฟเวอร์จะติ๊กช่องในตารางให้เอง:
  กระโดดเชือก ≥ 8 นาที → ช่องเชือก · วิ่ง ≥ 15 นาที → ช่องวิ่ง (หรือช่องเชือกถ้าวันนั้นไม่มีวิ่ง) · เวท/มวย ≥ 15 นาที → ช่องเวท/มวย
- ดูข้อมูลได้ที่หน้า **📋 รายวัน** ใต้ตารางซ้อม (การ์ด **⌚ Apple Watch**) และป้ายเขียวตรงช่องที่นาฬิกาบันทึก
- การอ่านข้อมูลเปิดเหมือนข้อมูลสัปดาห์ (ใครมี URL ก็ดูได้) การเขียนต้องใช้ key หรือ PIN

## 1. นำเข้าข้อมูลย้อนหลัง (ครั้งเดียว)
แอป → ⚙️ ตั้งค่า → **⌚ Apple Watch** → **📥 นำเข้าไฟล์ .json** → เลือก `health-digest.json` (ใส่ PIN ถ้าถาม)
> ⚠️ อย่าเอา `health-digest.json` ใส่ใน repo — ทุกไฟล์ใน repo เปิดดูได้บนเว็บ

## 2. สร้าง Shortcut "Southpaw Sync"
เปิดแอป **คำสั่งลัด (Shortcuts)** → แท็บ **คำสั่งลัด** → **+**
> ชื่อเมนูภาษาไทยอาจต่างจากนี้เล็กน้อย พิมพ์คำในวงเล็บที่ช่องค้นหา action ได้

**ก้าวเดิน**
1. เพิ่ม **ค้นหาตัวอย่างสุขภาพ** (Find Health Samples) → ประเภท **จำนวนก้าว (Steps)** → ตัวกรอง **วันที่เริ่มต้น อยู่ใน วันนี้ (Start Date is Today)**
2. เพิ่ม **คำนวณสถิติ** (Calculate Statistics) → **ผลรวม (Sum)**
3. เพิ่ม **ตั้งค่าตัวแปร** (Set Variable) → ชื่อ `steps`

**ทำซ้ำข้อ 1–3 อีก 3 ชุด** เปลี่ยนแค่ประเภทกับชื่อตัวแปร
| ประเภท | สถิติ | ตัวแปร |
|---|---|---|
| พลังงานที่ใช้ขณะเคลื่อนไหว (Active Energy) | ผลรวม | `active` |
| เวลาออกกำลังกาย (Exercise Minutes) | ผลรวม | `exmin` |
| ระยะทางเดินและวิ่ง (Walking + Running Distance) | ผลรวม | `km` |
| ความแปรปรวนของอัตราการเต้นหัวใจ (Heart Rate Variability) | ค่าเฉลี่ย (Average) | `hrv` |

**ชีพจรขณะพัก**
- **ค้นหาตัวอย่างสุขภาพ** → **อัตราการเต้นของหัวใจขณะพัก (Resting Heart Rate)** → วันที่เริ่มต้นอยู่ในวันนี้ → เรียงตาม **วันที่เริ่มต้น ล่าสุดก่อน** → **จำกัด 1** → **ตั้งค่าตัวแปร** `rhr`

**Workout (ถ้า iOS ของคุณมีประเภท "Workouts / การออกกำลังกาย" ในรายการ)**
1. **ค้นหาตัวอย่างสุขภาพ** → ประเภท **Workouts** → วันที่เริ่มต้นอยู่ในวันนี้
2. **ทำซ้ำกับแต่ละรายการ** (Repeat with Each) แล้วข้างในใส่ **พจนานุกรม** (Dictionary):
   - `type` = รายการที่ทำซ้ำ → **ชนิด/ชื่อ (Type/Name)**
   - `start` = รายการที่ทำซ้ำ → **วันที่เริ่มต้น (Start Date)**
   - `min` = รายการที่ทำซ้ำ → **ระยะเวลา (Duration)**
   - `kcal` = รายการที่ทำซ้ำ → **พลังงาน (Energy)** ถ้ามี
   - `km` = รายการที่ทำซ้ำ → **ระยะทาง (Distance)** ถ้ามี
3. หลัง **สิ้นสุดการทำซ้ำ** → **ตั้งค่าตัวแปร** `workouts`

> ถ้าไม่มีประเภท Workouts ให้ข้ามส่วนนี้ ข้อมูลรายวันยังส่งได้ปกติ แต่การติ๊กอัตโนมัติจาก Workout จะไม่ทำงาน (ทางเลือกคือแอป Health Auto Export ซึ่งส่ง Workout ได้ครบ ส่งมาที่ URL เดียวกันได้)


**ข้อมูลเพิ่ม (ไม่บังคับ แต่ส่งมาแล้วแอปจะแสดงให้)** ทำแบบเดียวกับข้างบน แล้วเพิ่มช่องในเนื้อหา JSON
| ประเภทใน Health | สถิติ | ชื่อช่อง |
|---|---|---|
| พลังงานขณะพัก (Resting/Basal Energy) | ผลรวม | `basal` → แอปคำนวณ kcal ทั้งวันให้ |
| ชั้นที่ขึ้น (Flights Climbed) | ผลรวม | `flights` |
| เวลาในแสงแดด (Time in Daylight) | ผลรวม | `daylight` |
| ความเร็วในการเดิน (Walking Speed) | ค่าเฉลี่ย | `wspeed` |
| อัตราการเต้นหัวใจเฉลี่ยขณะเดิน (Walking Heart Rate Average) | ค่าเฉลี่ย | `walkhr` |
| ออกซิเจนในเลือด (Blood Oxygen) | ค่าเฉลี่ย | `spo2` (ส่ง 0.97 หรือ 97 ก็ได้) |
| อัตราการหายใจ (Respiratory Rate) | ค่าเฉลี่ย | `resp` |
| ชั่วโมงยืน (Stand Hours) | จำนวน | `standh` |
| การนอน (Sleep) | ผลรวมชั่วโมง | `sleep` |

**วันที่**
- **จัดรูปแบบวันที่** (Format Date) → **วันที่ปัจจุบัน** → รูปแบบ **กำหนดเอง** `yyyy-MM-dd` → ตั้งค่าตัวแปร `date`

**ส่งข้อมูล**
- **รับเนื้อหาของ URL** (Get Contents of URL)
  - URL: `https://www.ifrank.club/api/southpaw-health`
  - วิธี (Method): **POST**
  - เฮดเดอร์ (Headers): `x-southpaw-key` = รหัสเดียวกับ `SOUTHPAW_KEY`
  - เนื้อหาคำขอ (Request Body): **JSON** แล้วเพิ่มช่อง
    `date`, `steps`, `active`, `exmin`, `km`, `rhr`, `hrv` (เลือกตัวแปรชื่อเดียวกัน) และ `workouts` (ถ้ามี)
- (ไม่บังคับ) **แสดงการแจ้งเตือน** (Show Notification) → เนื้อหาของ URL เพื่อดูผล

กด ▶︎ ลองรัน ต้องขึ้น `{"ok":true,...}` แล้วเปิดแอป → หน้ารายวัน เลื่อนลงใต้ตารางซ้อม จะเห็นข้อมูลวันนี้ในการ์ด "⌚ Apple Watch"

> ส่งค่ามาแบบมีหน่วยติดได้ เช่น `12,345 ก้าว` หรือ `61 ครั้ง/นาที` เซิร์ฟเวอร์จะตัดเหลือแต่ตัวเลขให้เอง ส่งซ้ำวันเดิมก็ได้ จะทับค่าเก่า ไม่ซ้ำซ้อน

## 3. ตั้งให้ทำงานเองทุกคืน
แท็บ **ระบบอัตโนมัติ (Automation)** → **+** → **เวลาของวัน (Time of Day)** → **23:30** · **ทุกวัน**
→ เลือก **เรียกใช้ทันที (Run Immediately)** และปิด **แจ้งเตือนเมื่อเรียกใช้** ถ้าไม่อยากเห็น
→ เลือกคำสั่งลัด **Southpaw Sync**

ตั้ง 23:30 เพื่อให้รวม Workout ตอนเย็นด้วย

## เช็คว่าเซิร์ฟเวอร์รับได้ (จากคอม)
```bash
curl -X POST "https://www.ifrank.club/api/southpaw-health" \
  -H "x-southpaw-key: ค่า SOUTHPAW_KEY" -H "Content-Type: application/json" \
  -d '{"date":"2026-10-30","steps":"12,345","rhr":61}'
```
| ผล | ความหมาย |
|---|---|
| `{"ok":true,...}` | ✅ ใช้ได้ |
| `401 locked` | key ไม่ตรงกับ `SOUTHPAW_KEY` |
| `400 no data` | ไม่มีตัวเลขในค่าที่ส่ง เช็คชื่อช่องใน JSON |
| `500 server not configured` | ไม่มี `MONGODB_URI` หรือ `SOUTHPAW_KEY` |
