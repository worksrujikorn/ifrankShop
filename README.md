# ifrankShop

เว็บร้าน iFrank ออกแบบให้ใช้บนมือถือเป็นหลัก ทำด้วย HTML/CSS/JS ล้วน และรันบน Vercel
หน้าตาอ้างอิงจากงานออกแบบใน Stitch ใช้ธีม **Candy Pop**

- หน้าร้าน: `https://ifrank.shop` (เป็นลิงก์ส่วนตัว ตั้งค่า noindex ไว้ทั้งเว็บ)
- หลังบ้าน: `https://ifrank.shop/admin`
- ตัวอย่างธีม: `https://ifrank.shop/themes`

---

## 1. หน้าร้าน — แอป 4 แท็บ (`index.html`)

| แท็บ | สิ่งที่มี |
|---|---|
| 🏪 **หน้าร้าน** | แถบประกาศ 20+ (ปิดได้), ชิปหมวดหมู่, ค้นหา, การ์ดสินค้าที่เลือกขนาดได้บนการ์ดและมีปุ่ม **+ ใส่ตะกร้า**, badge, ป้าย "หมดชั่วคราว", ท้ายเว็บมีลิงก์นโยบายและคำเตือนตามกฎหมาย |
| 🧪 **กลิ่นสัมผัส** | Terpene & Flavor Lab: ตัวเลขสรุปที่คำนวณจากเมนูจริง, ชิปอารมณ์ (Focus / Relax / Creative / Deep Rest / Social), กราฟเรดาร์กลิ่น 6 แกน, การ์ดเทอร์ปีนพร้อม % ความเด่นและสายพันธุ์แนะนำ, ปุ่ม "เลือกกลิ่นนี้" ที่พากลับไปหน้าร้านพร้อมตัวกรอง |
| 🧾 **ใบสั่งซื้อ** | ใบสั่งซื้อแบบสลิป มีเลข `#IF-MMDD-XXXX` พอดีหนึ่งจอให้แคปได้ทันที, ปุ่มบันทึกเป็นรูป (มือถือจะเปิดเมนูแชร์เข้าแอปแชทได้เลย), คัดลอกข้อความ, ประวัติ 10 ใบล่าสุด |
| ⚙️ **ตั้งค่า** | ลูกค้าเลือกธีมเฉพาะเครื่องตัวเองได้, วิธีสั่งซื้อ, นโยบาย 20+, ล้างข้อมูลในเครื่อง |

**ขั้นตอนสั่งซื้อ:** เลือกสินค้า → เปิดตะกร้า → **ยืนยันออเดอร์** → ได้ใบสั่งซื้อ → ลูกค้าแคปส่งในแชทที่คุยกับร้าน
- บนเว็บไม่มีการตัดเงิน
- เซิร์ฟเวอร์คำนวณราคาใหม่เสมอ ลูกค้าแก้ราคาเองไม่ได้
- ออเดอร์จะเข้าคิวในหลังบ้านด้วย (เมื่อเชื่อมฐานข้อมูลแล้ว)

## 2. หลังบ้าน (`admin.html`)

| แท็บ | สิ่งที่มี |
|---|---|
| 📊 **ภาพรวม** | สถานะร้าน, ยอดวันนี้ (นับเฉพาะออเดอร์ที่ยืนยันแล้ว), ออเดอร์รอยืนยัน, สายพันธุ์พร้อมขาย / ใกล้หมด, คำสั่งด่วน, **คิวออเดอร์** (ยืนยัน → ส่งแล้ว / ยกเลิก), สวิตช์สต็อก, แก้แถบประกาศ |
| 📦 **สินค้า** | เพิ่ม แก้ไข ทำสำเนา ลบ ซ่อน และเรียงลำดับสินค้า, สวิตช์มีของ/หมด, badge ด่วน, ตัวเลือก emoji, ราคาหลายขนาด, สีการ์ด, **เทอร์ปีนพร้อมระดับ %** และ **โปรไฟล์กลิ่น 0–5 พร้อมดูกราฟเรดาร์ได้ทันที** |
| 🗂️ **หมวดหมู่** | ตั้งชื่อ ไอคอน คำอธิบาย สี และเรียงลำดับ |
| ⚙️ **ตั้งค่าร้าน** | ธีม 8 แบบ, ชื่อร้าน, สโลแกน, ประกาศ, ข้อความจัดส่ง, เวลาเปิด, ข้อความบนใบสั่งซื้อ, ถามอายุ 20+ |
| 💾 **สำรองข้อมูล** | Export / Import JSON และยกเลิกการแก้ไขทั้งหมด |

## 3. โครงสร้างไฟล์

```
index.html            หน้าร้าน (แอป 4 แท็บ)
admin.html            หลังบ้าน
themes.html           แกลเลอรีธีม
assets/shared.js      ธีม, badge, สีการ์ด, เทอร์ปีน, อารมณ์, แกนกลิ่น, กราฟเรดาร์
api/products.js       เมนู: GET อ่าน (สาธารณะ) / POST บันทึก (ต้องใช้รหัสแอดมิน)
api/orders.js         ออเดอร์: POST สร้าง (สาธารณะ) / GET ดูรายการ, PATCH เปลี่ยนสถานะ (แอดมิน)
api/_lib.js           ฟังก์ชันที่ใช้ร่วมกัน (ไม่ใช่ route)
data/products.json    ข้อมูลตั้งต้น / ข้อมูลสำรอง
vercel.json           URL แบบไม่มี .html + noindex ทั้งเว็บ
```

## 4. Deploy

```bash
git add index.html admin.html themes.html assets api data vercel.json README.md
git commit -m "mobile app redesign: shop, terpene lab, order slip, admin dashboard"
git push
```

Vercel จะ deploy ให้อัตโนมัติ แล้วตั้งค่าใน Vercel ครั้งเดียว:

1. **Storage** → Create → **Upstash Redis** (แพ็กเกจฟรี) → Connect to Project ifrank-shop
2. **Settings → Environment Variables** → เพิ่ม `ADMIN_PASSWORD`
3. **Deployments** → **Redeploy**
4. เข้า `/admin` → มุมบนต้องขึ้น **● Online**

ถ้ายังไม่ได้ทำข้อ 1:
- หน้าร้านยังใช้ได้ปกติ ลูกค้าแคปใบสั่งซื้อได้
- คิวออเดอร์จะยังว่าง
- หลังบ้านจะบันทึกได้แค่การดาวน์โหลด `products.json`

## 5. ปรับแต่งเพิ่ม

- **ธีม:** `THEMES` ใน `assets/shared.js`
- **Badge:** `BADGES`
- **สีการ์ด:** `FLAVORS`
- **เทอร์ปีน / อารมณ์ / แกนกลิ่น:** `TERPENES`, `MOODS`, `PROFILE_AXES`
- คำอธิบายเทอร์ปีนเขียนเป็นแค่ "กลิ่นและฟีลทั่วไป" ไม่ใช่สรรพคุณทางการแพทย์ ถ้าแก้ควรคงแนวนี้ไว้
- **ทดสอบในเครื่อง:** `npx vercel dev`
